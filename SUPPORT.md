# Support

OwnMinutes is maintained on a best-effort basis.

## Where to ask

- Use the bug report form for reproducible defects.
- Use the feature request form for focused product proposals.
- Use pull requests for reviewed code and documentation changes.

Before opening an issue, search existing issues and reproduce the problem on the
latest default branch when practical. Include operating system, Node/npm
versions, the affected commit, expected behavior, actual behavior, and a minimal
synthetic reproduction.

## Public-data boundary

Do not post real recordings, transcripts, account exports, credentials, cookies,
tokens, production URLs, private infrastructure details, or customer data.
Redact logs before attaching them. Report security problems through
[SECURITY.md](SECURITY.md), not through a public issue.

## What is not guaranteed

The project does not currently provide guaranteed response times, private
deployment consulting, legal advice, provider billing support, or recovery of
self-hosted data. Community help and commercial support may be added later.
