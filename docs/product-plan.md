# OwnMinutes 产品方案

## 定位

OwnMinutes是实时会议记录和知识沉淀工具。第一版不做完整会议软件，而是把一次真实会议转成可分享、可检索、可沉淀到Obsidian的组织记忆。

## MVP目标

- 点击开始录音，不需要手动上传音频。
- 会议中生成实时逐字稿、阶段摘要、待办候选和决策候选。
- 会议结束后基于完整音频生成详细纪要。
- 识别不同发言人，第一版允许用Speaker 1、Speaker 2占位并会后改名。
- 生成可分享链接。
- 生成结构化Obsidian Markdown。

## 非目标

- 第一版不做完整会议软件。
- 第一版不做IM、日历、组织架构和复杂审批流。
- 第一版不承诺单设备混合录音下的实时高精度说话人识别。

## 核心流程

```text
创建会议
-> 点击开始录音
-> 实时转写
-> 阶段摘要和候选待办
-> 点击结束会议
-> 会后说话人识别和逐字稿校正
-> 生成正式纪要
-> 发布分享链接
-> 写入Obsidian知识库
```

## 第一版页面

- 会议录制工作台：首页，包含录音控制、实时逐字稿、阶段摘要、决策候选、待办候选。
- 分享页：给外部查看的纪要页面。
- 后续设置页：配置Obsidian vault路径、模板、分享权限。

## 风险

- 单设备录音的说话人识别准确率有限，需要后处理和人工改名。
- 会议录音有隐私和授权风险，必须加入参会人知情、删除和分享权限控制。
- Obsidian沉淀不能只是堆Markdown，需要项目、决策、待办和标签规则。
